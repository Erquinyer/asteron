# Retrospectivas de sprint

Plantilla: [`plantilla-retrospectiva.md`](plantilla-retrospectiva.md). Copien un archivo por sprint (`sprint-06.md`, `sprint-07.md`, …) y llénenlo entre los tres al cerrar cada sprint. La lista de chequeo T6 (ítem 2) pide **al menos 2 sprints** con retrospectiva que incluya una **reflexión explícita sobre el proceso de pruebas** (sección 4 de la plantilla).
